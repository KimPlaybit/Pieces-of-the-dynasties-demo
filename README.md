# Pieces of the Dynasties — Demo

A playable browser demo of *Pieces of the Dynasties*. It runs entirely in the browser
(WebAssembly + WebGL2); there is no server-side code.

Hosted with GitHub Pages: https://kimplaybit.github.io/Pieces-of-the-dynasties-demo/

To run it elsewhere, serve this folder with any static web server. `index.html` sets
`<base href="/Pieces-of-the-dynasties-demo/">` for GitHub Pages; change it to `/` to serve the
demo from the root of a site.
